## Why

The `SUMMARY.md` generated by `sleap-roots-analyze run-all` only contains basic execution metadata (config name, status, time, output path) but is missing the scientific results required by the spec. Users cannot see sample counts, trait counts, genotype counts, heritability values, or removed traits without manually inspecting individual `pipeline_summary.json` files.

The existing spec (`pipeline-runner-skill`) requires:

- **QC summary**: Dataset, Samples, Traits, Genotypes, H² Threshold, Mean H², removed traits
- **Viz summary**: Dataset, Elapsed Time, Status, key visualization parameters
- **Cross-platform summary**: Comparison, Common Genotypes, Exp1/Exp2 Samples/Traits
- **Methods section**: Publication-ready template

## What Changes

- **MODIFIED** `PipelineRunner._format_qc_summary()` to read `10_pipeline_summary.json` from each QC run and extract:
  - `final_data.n_samples`, `final_data.n_traits`, `final_data.n_genotypes`
  - `configuration.heritability.threshold`
  - `step_summaries.heritability_filter.mean_heritability_retained`
  - `step_summaries.heritability_filter.removed_trait_names`

- **MODIFIED** `PipelineRunner._format_viz_summary()` to include key visualization parameters from config

- **MODIFIED** `PipelineRunner._format_cross_platform_summary()` to read `pipeline_summary.json` and `cross_platform_alignment_summary.csv` to extract:
  - Common genotypes count
  - Exp1/Exp2 sample and trait counts

- **ADDED** `PipelineRunner._format_methods_section()` to generate publication-ready methods template

- **ADDED** helper functions to safely read and parse pipeline summary JSON files

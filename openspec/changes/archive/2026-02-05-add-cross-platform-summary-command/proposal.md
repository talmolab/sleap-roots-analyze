# Add Cross-Platform Summary Command

## Why

The current `run-pipelines` command generates a basic `SUMMARY.md` that lacks detailed cross-platform analysis reporting. Scientists need comprehensive, reproducible summaries that include trait reduction statistics, correlation counts, top correlations with statistical power and significance, and complete metadata for publication and review. Without guardrails verifying accuracy, there's risk of reporting incorrect statistics.

Additionally, the current trait clustering implementation implicitly clusters only exp2 traits without explicit configuration. This is unclear and not reproducible. Scientists need explicit control over which experiment(s) to cluster, with clear visualization of the clustering results.

## What Changes

### Configuration
- **MODIFIED**: `CrossPlatformConfig` requires explicit `trait_reduction_target` when clustering is enabled
  - Options: `exp1`, `exp2`, or `both`
  - Validation fails if missing when `trait_reduction_method: clustering`
- **BREAKING**: Existing configs with clustering enabled must add `trait_reduction_target`

### Pipeline Steps
- **MODIFIED**: `ReduceTraitRedundancyStep` supports clustering exp1, exp2, or both experiments
  - Outputs `exp1_trait_clusters.csv` and/or `exp2_trait_clusters.csv`
  - Generates per-experiment clustering visualizations
- **MODIFIED**: `VisualizeCrossPlatformStep` generates cross-platform representative heatmap

### Visualizations (generated by pipeline steps)
- **NEW**: `exp1_trait_clustering_dendrogram.png` - hierarchical clustering tree (if exp1 clustered)
- **NEW**: `exp1_trait_cluster_heatmap.png` - within-exp1 correlation matrix (if exp1 clustered)
- **NEW**: `exp2_trait_clustering_dendrogram.png` - hierarchical clustering tree (if exp2 clustered)
- **NEW**: `exp2_trait_cluster_heatmap.png` - within-exp2 correlation matrix (if exp2 clustered)
- **NEW**: `cross_platform_representative_heatmap.png` - exp1 vs exp2 representative correlations

### Summary Generation
- **NEW**: `/cross-platform-summary` Claude command for on-demand reporting
- **MODIFIED**: `run-pipelines` command auto-generates detailed cross-platform summary
- **NEW**: Summary validation guardrails verify statistics match source CSVs
- **NEW**: Embedded visualizations in markdown (correlation summary, top 3 joint plots, clustering viz)
- **NEW**: Comprehensive statistics tables (trait reduction, correlations, significance, power)

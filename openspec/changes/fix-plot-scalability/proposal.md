## Why

Pipeline plots have multiple issues affecting readability, correctness, and completeness:

1. **Config confusion**: PCA biplot is controlled by `static_viz.pca_biplot_top_features` (default 10), not `pca.n_top_features` (set to 1 in configs). Both default to 10 but serve different purposes -- this should be documented more clearly in config templates
2. **Unreadable labels**: Heritability, correlation, EDA, and variance decomposition plots produce illegible x-axis labels at 100+ traits (cylinder EDPIE)
3. **Missing outputs**: UMAP step is a stub (Phase 2C) but config enables it silently; static UMAP visualization functions exist but aren't wired into the pipeline
4. **Excessive files**: Cylinder generates 656 batch files (98 boxplot + 66 histogram batches, PNG + PDF each)
5. **Inconsistent label formatting**: Cross-platform plots apply ad-hoc `.replace('_', ' ').title()` instead of reusing the existing `sanitize_trait_names()` from `data_utils.py`
6. **Missing notebook plots**: Systematic comparison of 38 Jupyter notebooks vs pipeline output revealed 8 non-UMAP plot types used in notebooks that are not generated by the pipeline (see `local_notes/plot_inventory_2026-02-05.md` for full inventory)

## What Changes

### P0 - Label Readability for High Trait Counts
- **Heritability bar plot** (`create_heritability_plot` in `visualization.py:754`): Fixed (12,6) figsize with 90-degree rotated 8pt labels creates unreadable black mass at 100+ traits. Fix: paginate into readable batches (similar to existing histogram/boxplot batching) or show top-N sorted bars with full data preserved in CSV export
- **Correlation heatmap** (`create_correlation_heatmap` in `visualization.py:328`): Fixed (12,12) causes label overlap at 100+ traits. Fix: scale figure size adaptively with trait count, use smaller font with adequate spacing, or group by trait category
- **Variance decomposition** (`create_variance_decomposition_plot` in `visualization.py:930`): Same x-axis label crowding. Fix: paginate or show sorted top-N per panel with summary statistics
- **EDA overview** (`create_trait_eda_plots` in `visualization.py:486`): Bottom IQR panel x-axis labels overlap. Fix: scale figure width with trait count and reduce font size, or paginate panels
- **PCA biplot label overlap** (`create_pca_biplot` in `visualization.py:1726`): Feature loading labels overlap in dense regions even at correct feature count. Fix: use adjustText library for automatic label placement

### P1 - Memory Safety During Figure Generation
- Add `matplotlib.pyplot.close()` calls after every figure save to prevent memory accumulation when generating hundreds of batch plots sequentially
- Ensure `gc.collect()` is called between large heatmap/dendrogram generations
- Add memory-aware guards so the pipeline logs warnings and degrades gracefully rather than freezing

### P2 - Excessive File Generation
- Cylinder experiment generates **98 boxplot batches** + **66 histogram batches** = 656 files (PNG + PDF each)
- Increase `traits_per_batch` adaptively (e.g., 4 -> 9 subplots per page when trait count > 50) to reduce total batch count
- Make PDF generation optional via config (currently doubles file count for every figure)

### P3 - Label Formatting Consistency
- Cross-platform joint plots and boxplots (`cross_experiment_analysis.py:1508`) use ad-hoc `.replace('_', ' ').title()` instead of reusing the existing `sanitize_trait_names()` function from `data_utils.py`. Fix: apply consistent label formatting using existing utility
- Inconsistent directory naming: QC uses `figures/`, Viz uses both `figures/` and `static_figures/`

### P4 - UMAP Stub Transparency
- **UMAP step is a stub** (`umap_analysis.py`): Logs "UMAP analysis not yet implemented (Phase 2C)" and returns immediately. Config allows `umap.enabled: true` without warning that it's non-functional. Fix: make config validation warn that UMAP is not yet available

### P5 - Missing Static UMAP Visualizations (deferred if UMAP stays stub)
- `create_umap_colored_by_top_traits()` and `create_umap_single_trait()` exist in `visualization.py` but are NOT imported or called in `generate_static_figures.py`
- `interactive_umap.html` is never generated because `umap_results` is always None
- If/when UMAP is implemented, these need to be wired into the pipeline steps

### P6 - Missing Notebook Plots (not blocked by UMAP)
Systematic comparison of 38 Jupyter notebooks vs pipeline steps revealed these plot types are used in notebooks but not generated by the pipeline. All functions already exist in the codebase -- they just need to be wired into pipeline steps.

**Static plots (add to `generate_static_figures.py`):**
- **PCA feature contribution bar chart** (`create_feature_contribution_plot` in `visualization.py`): Stacked horizontal bar chart showing per-PC variance contributions for top N features. Called in ALL viz notebooks. Not in pipeline.
- **Phenotype variation plots** (`create_phenotype_variation_plot` in `visualization.py`): Box+strip plot per trait showing genotype distributions with extreme genotype highlighting (red/blue) and mean+SD lines. Called in ALL viz notebooks in a loop over selected traits. Not in pipeline.
- **Regression plots** (`create_regression_plot` in `visualization.py`): Scatter with fitted regression line, R-squared, p-value, Pearson r, and equation annotation. Called in turface and root_coring notebooks for trait-trait relationships. Not in pipeline.
- **Genotype image grids** (`create_genotype_image_grid` in `visualization.py`): Grid of actual root images for extreme genotypes identified by PCA. Called in ALL viz notebooks with image linking. Requires image paths from config. Not in pipeline.

**Interactive plots (add to `generate_interactive.py`):**
- **Interactive scatter with images** (`create_interactive_scatter_with_images` in `interactive_visualization.py`): General Plotly scatter for any two variables with image hover. Called in ALL viz notebooks with images. Not in pipeline.
- **HTML image viewer** (`create_html_with_image_viewer` in `interactive_visualization.py`): Full HTML page with Plotly plot on left and click-to-view image panel on right. Called in ALL viz notebooks with images. Not in pipeline.
- **Image gallery** (`create_interactive_image_gallery` in `interactive_visualization.py`): Browsable HTML gallery of sample images with trait value tooltips. Called in ALL viz notebooks with images. Not in pipeline.

**QC plots (add to `visualize_outliers.py`):**
- **Outlier method comparison bar chart**: Inline matplotlib bar chart showing outlier counts per detection method with value labels. Present in ALL QC notebooks as inline code. Not in pipeline as a dedicated figure.
